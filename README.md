# weather-app
A lightweight and responsive weather widget that displays the temperature, wind speed, and humidity for any location in the world.

🔧 Built with: HTML, CSS, JavaScript

🌍 Features:

🌡️ Real-time temperature
💨 Wind speed
💧 Humidity levels
📍 Search by city or location name
⚡ Fast and easy to use
